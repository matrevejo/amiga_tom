WHDLoad funktioner

  • startbar via CLI eller Workbench
  • hukommelsesbeskyttelse benyttelse af MMU (hvis tilgængelig)
  • absolut ren returnering til OS'et (afhænger af Slaven)
  • mulighed for at bruge "disk images" og/eller ordinære filer
  • mulighed for omdirigering skrevne filer til en separat filsystems-lokation, for at holde gemninger adskilt
  • variabel chip-memory størrelse for det installerede program fra $2000 op til $200000
  • ubegrænset fast-memory størrelse for det installerede program
  • intelligent allokering af chip-memory, delvis absolut and delvis uafhængig
  • caching af filer and disk images on startup og dynamisk ved kørsel (LRU)
  • automatisk decrunching af filer og disk images vha. XPK
  • automatisk decrunching af filer hvis Slaven understøtter det (RNC/IMP/TPWM/CRM)
  • emulation af MOVE SR,ea from User-Mode on 68010+
  • emulation af ikke-understøttede heltals-instruktioner på 68060
  • advanceret fejlfindings-support (memory dump, register dump, filadgangs-logging, detektering af Brugerdefinerede register-adgange)
  • Enforcer/Cyberguard og VMM proof så længe option NoVBRMove/S ikke bliver anvendt
