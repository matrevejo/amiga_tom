Patcher * Patching Programmer

Patcheren er et universalværktøj til at modificere filer eller diske. Det var det foretrukne værktøj for WHDLoad installationer til at oprette filer eller disk-images fra originaldiske med et meget personligt diskformat i tidligere udgaver af WHDLoad-pakken. Det foretrukne værktøj for denne opgave er RawDIC nu. For at lære mere om Patcheren bør du læse dens dokumentation, hvilken også kan finde i patcher-arkivet vedlagt DEV pakken i WHDLoad.

Patcher behøver ruby.8 font! Du kan finde denne font på dine originale Workbench-disketter. Hvis fonten ikke er tilgængelig, vil Patcheren ganske enkelt ikke starte.

Egenskaber:

  • nemt valg af kildedrev
  • diskrutine kan ikke fejle som følge af for hurtig cpu
  • virker på escom-amiga'er med diskdrive-hardware'egenskab'
  • multitasker mens den læser (det er endda muligt at installere 2 spil på samme tid hvis du ejer 2 diskdrev)
  • kan vise sporet mens den læser (nyttig for fejlrapporter) og imaging-problemer (læsefejl, disk fuld etc)
  • kan debugges med en normal debugger
Ulemper:
  • indledningsvis ~6-8 h nødvendigt for at sætte sig ind i det som programmør
  • måske større hukommelsesforbrug på ~1 MiB, afhængig af disk-imaget (men for folk med mindre end 2 MiB RAM er hdinstalls heller ikke så brugbare)
